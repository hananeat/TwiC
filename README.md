# TwiC

TwiC (Tiny Wellness Interactive Chick) is a gamified wellness and mood tracking mobile application built with Flutter. It combines health monitoring with a playful virtual pet companion (the chick) to encourage healthy habits and daily mindfulness. Users earn stars by logging their mood and completing daily wellness goals, which they can spend in the shop to grow and customize their virtual pet and its habitat.

# Features
- Gamified Wellness Companion: A virtual pet that evolves from an egg to an adult chick.
- Shop & Customization System: Earn stars through healthy habits to purchase new colors, accessories (e.g., summer hats, sunglasses), and habitat backgrounds (e.g., beach, forest, desert) for your pet.
- Mood Logger: Track your daily mood, log emotional tags (chips), and visualize mood trends over time.
- Health Data Integration: Connects with health data APIs to track physical wellness metrics like steps and activity.
- Data Persistence: Local storage via `SharedPreferences` to persist user data, mood logs, and shop inventory offline.
- Clean Responsive UI: Modern design following material guidelines with custom typography and smooth animations.
